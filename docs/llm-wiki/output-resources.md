# 回答中的链接、图片与资源操作

本轮统一主对话、侧边聊天和图片预览的资源交互。普通链接、自动识别的网址和行内代码中的网址共用 `OutputLink`；Markdown 图片保持图片预览，不再被转换成网址卡片。

## 操作约定

| 对象 | 左键 | 右键 |
| --- | --- | --- |
| HTTP(S) 链接 | 默认打开系统浏览器；保留外链确认设置与主对话的 ChatCut 路由 | 打开链接、在侧边浏览器打开（所在界面提供资源面板时）、复制链接 |
| 回答中的图片 | 打开原图预览；Enter／空格等价 | 查看大图、复制图片、图片另存为、复制图片地址／本地路径；本地文件可在系统文件管理器显示 |
| 大图预览中的图片 | 沿用缩放、切换与关闭 | 与缩略图共用原图操作；右键本身不会执行复制 |
| 已验证的本地文件 | 沿用资源面板预览 | 沿用打开、外部打开、显示位置、复制路径及详情；复制失败会显示提示 |
| 视频 | 沿用点击播放 | 播放、外部打开、复制链接／路径；本地视频可显示所在位置 |

“打开链接”当前沿用系统浏览器作为默认行为。Codex 自身窗口的读取被工具限制，未完成其当前版本的逐项菜单核对；这份表是本项目已实现并验证的行为基线，不代表已证实与 Codex 每项完全相同。

## 菜单与反馈

- 使用现有不透明 `ContextMenu`，菜单挂载到 body，靠近窗口边缘时限制位置；图片预览菜单高于大图层级。
- 保留文字选区时右击链接、图片、文件或视频，优先显示该资源菜单，隐藏文字选区工具条。
- 打开另一处菜单、滚动或调整窗口大小时关闭旧菜单；Escape 先关闭菜单，再处理预览／会话动作。
- 复制成功与操作失败使用不占对话高度的提示，避免再次拉动输出区域。保存过程中禁止重复操作；取消文件保存对话框不当作失败。
- 所有新菜单文字、处理状态和错误提示均进入 15 种语言目录。

## 原图与保存边界

- 复制／保存使用原始文件路径或原始 URL，不复制聊天缩略图。复制本地地址时使用文件路径，不暴露 loopback 媒体服务的令牌 URL。
- 本地预览仍使用现有路径解析与 loopback 服务；原图保存复用 `export_bytes_save`，用户在系统文件保存对话框选择位置。没有新增网络、鉴权或媒体协议实现。
- 保存原始字节，保留 GIF 等格式；沿用现有导出接口 40 MiB 限制。网页预览环境使用浏览器下载。
- 远程图片的复制／保存依赖原图可读取；服务器的跨域限制、链接失效、导出大小限制会显示失败提示。图片能够显示不等于浏览器允许读取其字节，不会以低清缩略图冒充保存成功。

## 验证入口

`pnpm test` 和 `pnpm build:ui`。主要交互回归位于 `OutputLink.test.tsx`、`ImageUi.interactions.test.tsx`、`ImageViewer.test.tsx`、`TranscriptSelectionToolbarHost.test.tsx`、`MarkdownChat.test.tsx` 和 `saveOutputImage.test.ts`。

浏览器测试覆盖浅色／深色、窗口右下角定位、保留选区的图片右键，以及大图菜单显示和逐层 Escape。系统浏览器、Finder 和保存面板通过既有 Host 接口与模拟回归验证，尚未用本轮代码制作安装包并在 macOS WebView 中实测。
